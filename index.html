Datenschutzerklärung — Grokbot / Gym Buddy

Stand: 1. November 2026

Verantwortlicher

Diese App („Grokbot“ / „Gym Buddy“) ist eine persönliche Fitness-Anwendung von Kolja Schenker. Kontakt: kolja.schenker@gmail.com

Welche Daten werden verarbeitet?

Über die Google Health API (read-only) können folgende Gesundheits- und Fitnessdaten gelesen werden:

  • Gewicht und Körperfettanteil
  • Workouts / Trainingseinheiten
  • Schlaf
  • Herzfrequenzvariabilität (HRV) und verwandte Messwerte

Zweck

Die Daten werden ausschließlich für das persönliche Trainingstracking und ein privates Dashboard des Betreibers verwendet.

Weitergabe an Dritte

Es erfolgt keine Weitergabe dieser Daten an Dritte. Es gibt keine Werbung und keinen Verkauf von Daten.

Speicherung

Die Daten werden nur so lange verarbeitet, wie sie für das persönliche Tracking benötigt werden. Der Zugriff kann jederzeit über das Google-Konto (Drittanbieter-Zugriffe) widerrufen werden.
